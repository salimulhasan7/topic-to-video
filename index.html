টপিক লিখুন

যে বিষয়ে ভিডিও চান, সেটা এক লাইনে লিখুন — বাংলা বা ইংরেজি দুটোই চলবে। চাইলে নিজের পয়েন্টও যোগ করতে পারেন।

২

স্ক্রিপ্ট ও আর্টওয়ার্ক

টপিক থেকে বাছাই করা মূল বিষয় (কেন গুরুত্বপূর্ণ, প্রভাব, উপকারিতা, চ্যালেঞ্জ, করণীয়…) নিয়ে পয়েন্ট-ভিত্তিক ইনফরমেটিভ স্ক্রিপ্ট আর প্রতিটা সিনের জন্য জেনারেটিভ সিনেমাটিক আর্টওয়ার্ক তৈরি হয়।

আপনার নিজের API

চাইলে নিজের LLM API (OpenAI-কমপ্যাটিবল) দিয়ে আসল তথ্যভিত্তিক স্ক্রিপ্ট আর Pixabay/Pexels দিয়ে রিয়েল ছবি — কী শুধু আপনার ব্রাউজারে থাকে।

সাধারণ প্রশ্ন

ভয়েস কীভাবে কাজ করে?

ব্রাউজারের বিল্ট-ইন টেক্সট-টু-স্পিচ ইঞ্জিন ব্যবহার হয়। উইন্ডোজ/ম্যাক-এ সেরা বাংলা ভয়েস (যেমন Microsoft Nabanita) পাবেন; লিনাক্সে মান ভেরিয়েন্টভেদে ভিন্ন হতে পারে। রেকর্ডের সময় ট্যাব অডিও ক্যাপচার করার অনুমতি দিলে ভয়েস ভিডিওতে যুক্ত হয়।

আউটপুট ফাইল কোন ফরম্যাটে?

WebM (VP9/VP8 + Opus) — GitHub, YouTube, Google Photos সব চলে। ব্রাউজারে সরাসরি এমবেডও হয়।

GitHub এ কীভাবে হোস্ট করব?

এই ফোল্ডারটা GitHub রিপোজিটরিতে পুশ করুন, তারপর Settings → Pages → "Deploy from a branch" → main/root সিলেক্ট করুন। এক মিনিটেই লাইভ। বিস্তারিত README-তে আছে।

স্ক্রিপ্ট কীভাবে তৈরি হয়?

টপিক থেকে ডিটারমিনিস্টিকভাবে ৪টা অ্যাঙ্গেল বাছাই হয় (কেন গুরুত্বপূর্ণ, প্রভাব, উপকারিতা, চ্যালেঞ্জ, করণীয়, ভবিষ্যৎ, বাস্তবতা) — প্রতিটা থেকে একটা করে "মূল বিষয়" সিন তৈরি হয়। একই টপিকে সবসময় একই স্ক্রিপ্ট পাবেন। চাইলে "নিজের পয়েন্ট" বক্সে আপনার গুরুত্বপূর্ণ পয়েন্টগুলো লিখলে (প্রতি লাইনে একটা) স্ক্রিপ্ট সেগুলো দিয়েই তৈরি হবে।

AI স্ক্রিপ্ট (LLM) কীভাবে চালু করব?

"উন্নত সেটিংস" খুলুন → AI স্ক্রিপ্ট চালু করুন → প্রোভাইডার বেছে নিন (OpenAI/DeepSeek/Groq/কাস্টম) → আপনার API কী দিন। স্ক্রিপ্ট তখন টেমপ্লেটের বদলে আসল AI থেকে টপিকের তথ্যভিত্তিক পয়েন্টসহ তৈরি হবে। "টেস্ট সংযোগ" বাটনে চেক করুন। কী শুধু আপনার ব্রাউজারে (localStorage) থাকে।

রিয়েল ছবি কীভাবে যুক্ত করব?

"উন্নত সেটিংস" → রিয়েল ছবি চালু করুন → Pixabay বা Pexels বেছে নিন → ফ্রি API কী দিন। তখন প্রতিটা সিনের ব্যাকগ্রাউন্ডে টপিক অনুযায়ী রিয়েল স্টক ফটো আসবে (কেন বার্নস মোশন আর সিনেমাটিক গ্রেডিং সহ)। কী না দিলে জেনারেটিভ আর্টওয়ার্কই চলবে।

LLM-এর স্ক্রিপ্ট ভালো না হলে?

প্রতিটা সিনে ✎ চাপ দিয়ে বক্তব্য সম্পাদনা করুন, তারপর "✔ স্ক্রিপ্ট সংরক্ষণ" চাপুন — সময়সূচি নিজে থেকেই হালনাগাদ হবে। আবার "ভিডিও তৈরি করুন" চাপলে নতুন করে স্ক্রিপ্ট আসবে।

ভিডিও কত লম্বা হয়?

টপিক অনুযায়ী সাধারণত ৪৫-৭০ সেকেন্ড — ৭টা সিন (টাইটেল + ৪ মূল বিষয় + সারমর্ম + আউটরো), ৩০ fps, 1280×720। নিজের পয়েন্ট দিলে পয়েন্ট সংখ্যা অনুযায়ী লম্বা হয়।
