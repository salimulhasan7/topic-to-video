# TopicToVideo

একটি টপিক লিখুন → সঙ্গে সঙ্গে সিনেমাটিক বাংলা ভিডিও তৈরি করুন। AI-স্টাইল জেনারেটিভ আর্টওয়ার্ক, ন্যাচারাল বাংলা ভয়েসওভার, সিন্থেসাইজড ব্যাকগ্রাউন্ড মিউজিক, Ken Burns মোশন, ক্রসফেড ট্রানজিশন আর Teal-Orange কালার গ্রেডিং — সব ১০০% ব্রাউজারে।

কোনো সার্ভার, কোনো ব্যাকএন্ড নেই। স্ট্যাটিক ফাইল — GitHub Pages-এ সরাসরি হোস্ট হয়। **ঐচ্ছিকভাবে** আপনার নিজের LLM API (OpenAI-কমপ্যাটিবল) আর স্টক ইমেজ API (Pixabay/Pexels) ব্যবহার করা যায় — কী শুধু আপনার ব্রাউজারে (localStorage) থাকে।

## বৈশিষ্ট্য

- **টপিক → ভিডিও:** বাংলা/ইংরেজি যেকোনো টপিক লিখলেই পয়েন্ট-ভিত্তিক ইনফরমেটিভ স্ক্রিপ্ট তৈরি হয় (টপিক-হ্যাশ থেকে ৪টা অ্যাঙ্গেল বাছাই: গুরুত্ব, প্রভাব, উপকারিতা, চ্যালেঞ্জ, করণীয়, ভবিষ্যৎ…)।
- **ঐচ্ছিক AI স্ক্রিপ্ট:** নিজের OpenAI-কমপ্যাটিবল LLM API কী দিলে টপিকের আসল তথ্যভিত্তিক স্ক্রিপ্ট আসে (OpenAI/DeepSeek/Groq/কাস্টম)।
- **ঐচ্ছিক রিয়েল ছবি:** Pixabay/Pexels API কী দিলে প্রতিটা সিনে টপিক অনুযায়ী রিয়েল স্টক ফটো (Ken Burns + গ্রেডিং সহ)।
- **নিজের পয়েন্ট:** "নিজের পয়েন্ট" বক্সে পয়েন্ট লিখলে (প্রতি লাইনে একটা) স্ক্রিপ্ট সেগুলো দিয়েই তৈরি হয়।
- **স্ক্রিপ্ট সম্পাদনা:** প্রতিটা সিনে ✎ চাপ দিয়ে বক্তব্য বদলান, "✔ স্ক্রিপ্ট সংরক্ষণ" চাপলেই সময়সূচি হালনাগাদ।
- **ন্যাচারাল বাংলা ভয়েস:** Web Speech API দিয়ে বাংলা ভয়েসওভার (উইন্ডোজ/ম্যাকে Microsoft Nabanita-র মতো নিউরাল ভয়েস পাওয়া যায়)।
- **জেনারেটিভ আর্টওয়ার্ক:** ৬ ধরনের সিনেমাটিক সিন (হুক, স্ট্রিক, সিলুয়েট, নোটিফিকেশন, রাত, সূর্যোদয়) — ক্যানভাসে রেন্ডার হয় (ছবি API না দিলে)।
- **সিনেমাটিক লুক:** Teal-Orange/সানসেট/মিডনাইট/ফরেস্ট থিম, ফিল্ম গ্রেইন, ভিনিয়েট, কালার গ্রেডিং।
- **সিনথেটিক BGM:** Web Audio API দিয়ে অ্যাম্বিয়েন্ট প্যাড, আরপেজিও আর হার্টবিট পালস।
- **রেকর্ড ও ডাউনলোড:** MediaRecorder দিয়ে WebM (VP9+Opus) এক্সপোর্ট। ভয়েসওভার যুক্ত করতে ট্যাব-অডিও শেয়ার।
- **গোপনীয়তা:** সব কিছু আপনার ব্রাউজারে প্রসেস হয়। API কীগুলো শুধু localStorage-এ থাকে — শুধুমাত্র আপনার ব্রাউজার থেকে সেই API-তে রিকোয়েস্ট যায়।

## API কী পেতে (ঐচ্ছিক)

### LLM স্ক্রিপ্ট
- OpenAI: platform.openai.com — `sk-…` কী
- DeepSeek: platform.deepseek.com — সস্তা বাংলা-বান্ধব
- Groq: console.groq.com — ফ্রি tier
- কাস্টম: যেকোনো OpenAI-কমপ্যাটিবল endpoint

অ্যাপে: **উন্নত সেটিংস → AI স্ক্রিপ্ট (LLM) চালু করুন → প্রোভাইডার/Base URL/মডেল/কী দিন → "টেস্ট সংযোগ"** দিয়ে যাচাই করুন।

### রিয়েল ছবি
- Pixabay: pixabay.com/api — ফ্রি কী
- Pexels: pexels.com/api — ফ্রি কী

অ্যাপে: **উন্নত সেটিংস → রিয়েল ছবি চালু করুন → প্রোভাইডার/কী দিন**। কী না দিলে জেনারেটিভ আর্টওয়ার্কই চলবে।

> **নিরাপত্তা নোট:** কী কখনো হার্ডকোড করা হয় না এবং কোনো সার্ভারে পাঠানো হয় না। এগুলো শুধু আপনার ব্রাউজারের localStorage-এ থাকে এবং সরাসরি API প্রোভাইডারে যায়। ফরম্যাট বাদ দিতে অ্যাপ সেটিংসে কী মুছে ফেলুন।

## GitHub Pages-এ হোস্ট করা

১. একটি GitHub রিপোজিটরি বানান (যেমন `topic-to-video`)।

২. এই ফোল্ডারের সব ফাইল রিপোজিটরিতে পুশ করুন:

```bash
git init
git add .
git commit -m "feat: TopicToVideo — client-side cinematic video maker"
git branch -M main
git remote add origin https://github.com/<username>/<repo>.git
git push -u origin main
```

৩. GitHub-এ রিপোজিটরিতে গিয়ে **Settings → Pages** খুলুন।

৪. **Build and deployment** এ "Deploy from a branch" সিলেক্ট করুন, branch `main` আর folder `/ (root)` চয়ন করুন, **Save** চাপুন।

৫. এক মিনিটের মধ্যে আপনার সাইট লাইভ: `https://<username>.github.io/<repo>/`

## লোকালি চালানো

যেকোনো স্ট্যাটিক সার্ভার দিয়েই চলবে:

```bash
python3 -m http.server 8000
# অথবা
npx serve .
```

ব্রাউজারে `http://localhost:8000` খুলুন।

## ব্যবহার

1. **টপিক লিখুন** (যেমন: "সোশ্যাল মিডিয়া আসক্তি") — চাইলে "নিজের পয়েন্ট" বক্সে পয়েন্ট দিন।
2. (ঐচ্ছিক) **উন্নত সেটিংস** খুলে LLM/ছবি API কী দিন।
3. ভয়েস (বাংলা) আর কালার থিম বেছে নিন।
4. **"ভিডিও তৈরি করুন"** চাপুন — স্ক্রিপ্ট আর সিন প্ল্যান দেখাবে।
5. (ঐচ্ছিক) প্রতিটা সিনে ✎ চাপ দিয়ে বক্তব্য সম্পাদনা → "✔ স্ক্রিপ্ট সংরক্ষণ"।
6. **▶ প্রিভিউ** — ব্রাউজারে ভিডিও দেখুন/শুনুন।
7. **● রেকর্ড ও ডাউনলোড** — WebM ফাইল ডাউনলোড হবে।
   - ভয়েসওভার ভিডিওতে যুক্ত করতে Chrome/Edge-এ ট্যাব শেয়ার করতে বলবে (অডিও সহ, "এই ট্যাব" বেছে নিন)।
   - ভয়েসওভার ছাড়া (শুধু মিউজিক) রেকর্ড করতে "ভিডিওতে ভয়েসওভার অন্তর্ভুক্ত করুন" আনচেক করুন।

## ফাইল কাঠামো

```
index.html         মূল পাতা (UI)

js/llm.js          OpenAI-কমপ্যাটিবল LLM → স্ক্রিপ্ট (ঐচ্ছিক)
js/images.js       Pixabay/Pexels → সিনে রিয়েল ছবি (ঐচ্ছিক)
js/artwork.js      ক্যানভাস জেনারেটিভ আর্টওয়ার্ক
js/bgm.js          Web Audio BGM
js/composer.js     টাইমলাইন, মোশন, ট্রানজিশন, ছবি রেন্ডার, রেকর্ডিং
js/app.js          UI নিয়ন্ত্রণ
```

## সীমাবদ্ধতা

- LLM স্ক্রিপ্ট শুধু কাজ করে যখন আপনি নিজের API কী দেন; না দিলে টেমপ্লেট স্ক্রিপ্ট ব্যবহার হয়। ব্রাউজার-থেকে-API CORS কনফিগারেশনের ওপর নির্ভরশীল।
- ভয়েস ব্রাউজার/অপারেটিং সিস্টেমের টেক্সট-টু-স্পিচ ইঞ্জিনের ওপর নির্ভর করে (লিনাক্সে বাংলা ভয়েস নাও থাকতে পারে)।
- এক্সপোর্ট WebM ফরম্যাটে — MP4 নয় (ব্রাউজার এনকোডিং সীমাবদ্ধতা)।
- রেকর্ডিং রিয়েল-টাইম — ভিডিও যত লম্বা, ততক্ষণ অপেক্ষা করতে হয়।
